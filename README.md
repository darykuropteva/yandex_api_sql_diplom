# Тест на проверку, что по треку заказа можно получить данные о заказе.
Структура проекта
 `sender_stand_request.py` - функции для отправки HTTP-запросов к API
 `configuration.py` - URL сервиса и пути запросов
 `data.py` - тестовые данные для создания заказа
 `order_track_test.py` - тест на проверку получения заказа по треку

Предусловие
Для запуска тестов должны быть установлены пакеты pytest и requests

Запуск тетса выполняется командой pytest
